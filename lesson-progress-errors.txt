LESSON PROGRESS API XATOLAR RO'YXATI
=====================================

GET /lesson-progress/get-videos
--------------------------------
Query parametr: blockId (required, integer)

1. 400 Bad Request
   - blockId parametr berilmagan yoki integer emas
   - ParseIntPipe validation xatosi

2. 404 Not Found
   - Block topilmadi (BlockNotFoundException)
   - "No lessons available" - darslar mavjud emas

3. 403 Forbidden
   - "Finish reviewing the previous tasks first." 
     (Vazifalar bo'limida 5 tadan ko'p vazifa bor)
   - "To access lessons beyond lesson 30 in module 1, you need to purchase this course."
     (To'lov qilinmagan yoki kurs aktiv emas)

4. 500 Internal Server Error
   - UserCourse topilmadi (userId va courseId bo'yicha)
   - Database xatolari
   - Block ID bo'yicha courseId topilmadi
   - generateLessonProgress jarayonida xatolik


PATCH /lesson-progress/:id
--------------------------
Path parametr: id (required, integer)

1. 400 Bad Request
   - id parametr integer emas
   - ParseIntPipe validation xatosi

2. 404 Not Found
   - LessonProgress topilmadi (LessonProgressNotFoundException)
   - LessonProgress.lesson null yoki undefined

3. 403 Forbidden
   - "Avvalgi vazifalarni yakunlang, so'ngra dars davom etadi."
     (Vazifalar bo'limida 5 tadan ko'p vazifa bor)
   - "To access lessons beyond lesson 30 in module 1, you need to purchase this course."
     (To'lov qilinmagan yoki kurs aktiv emas - 2 xil holat)

4. 200 OK (xabar bilan)
   - "Dars allaqachon ko'rilgan" (isWatched = true)
   - "Dars ko'rildi, ammo vazifa rejalashtirilmadi: ..."
   - "Dars ko'rildi, ammo uyga vazifani rejalashtirishda xatolik yuz berdi"

5. 500 Internal Server Error
   - Database transaction xatolari (rollback)
   - UserCourseProgress yangilashda xatolik
   - HomeworkProgress rejalashtirishda xatolik
   - Database connection xatolari


UMUMIY XATOLAR
--------------
- Authentication/Authorization xatolari (401, 403)
  (Auth decorator orqali tekshiriladi)
- Database connection xatolari
- TypeORM query xatolari
- Unexpected errors (try-catch ichida tutilmaydigan)
